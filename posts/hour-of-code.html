Hour of Code for October!

2026-10-06

Happy hour of code!

Are you interested in computer science? Do you like teaching? If you answered yes on both of those, then hour of code is for you! Each year in October we organize an Hour of Code trip to the elementary and middle schools where we teach younger students some fundamental computer science concepts in an engaging and interactive way, and hopefully funnel some of them into our high school CS courses in the future! If you're interested in signing up, get in contact with us to see if you're eligible!
