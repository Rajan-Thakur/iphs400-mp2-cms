# Project Report

* (a) What I built and which grill decisions were mine  
To build this project I used the AI only, and none of the code for the CMS is mine.
One major grill decision I made were to pivot away from a client-specific CMS to a general CMS with a separate client website built using the CMS. This was a major decision done in the early stage, which also led to me prompting it to change the already generated tech spec. This decision was influenced by new information about grading that I received verbally from Professor Chun about needing to create a general CMS with a website built on top of it, rather than a specific type of CMS.
Other grill decisions I made were generally refinements of what the AI proposed, such as what Admin/Editor permissions should look like (such as that Editors should be able to delete content, I decided to add this because it can make using the CMS quicker instead of having to get admin permission each time, and anyone that edits a website should be trusted with the content) and what the CMS features should be. This is all verifiable with the transcripts and the CONTEXT.md file. The decision date for all this is 9185fe8 on the 1st of October.
