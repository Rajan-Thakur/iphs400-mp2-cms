# Field notes

Looking at WordPress Playground and features in WordPress.

My observations:

1. Includes things like posts, pages, drafts, publication status, titles, text, and formatting for pages.
2. An editor that gives users the ability to edit those elements using a dashboard and an editor where they can edit everything on the website using tools and buttons.
3. There's the settings tab, which notably includes the feature to add application passwords and manage accounts, which is part of what an admin console includes.
4. There are also plugins, themes, and fonts to explore, which the user can select from and edit to their own liking. You can preview the site so that you can see how it all looks.
5. Unlike the playground, the real WordPress includes buttons for publishing or unpublishing, which actually allows you to look at the website that is published live, and people can see it on the web.
6. There's a media section allowing you to add your own files, which can be used for images, videos, or other items.
7. The posts section specifically allows you to post things on the website so that website visitors can see it.

My client will be Dr. Diane Kahle, the faculty advisor at the Upper Arlington High School Computer Science Honor Society. Using a CMS that I'll build, I'll create a website for UAHS CSHS. The website will be needed to promote computer science to students. A latest posts page would very helpful for that, because there'll be many events that are either completed or upcoming that can be listed for other students to see. Additionally there'll be multiple static informational pages with links to other resources, such as the computer science coursework offered or eligiblity requirements and so on.
